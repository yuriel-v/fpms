# FPMS Frontend

Placeholder for the React + TypeScript frontend (Vite, MUI, React Query).

This directory is scaffolded in **Task 7 — Frontend bootstrap** and fleshed out
across subsequent tasks:

- Vite `react-ts` app with MUI, React Query, and a router with protected routes.
- API client with an env-based base URL (`VITE_API_BASE_URL`).
- Currency formatter util (minor↔major units by currency exponent).
- Register/Login screens and the monthly Statement view.

Until then, the `frontend` service in `docker-compose.yml` is a placeholder.
